# ServicePulse — System Services Monitor

A cross-platform system monitoring app built from **one shared web codebase** (`app/`), packaged for:

| Target | Shell | Data source |
|---|---|---|
| **Windows desktop** | Electron (`electron/`) | Real CPU load, memory, and the running process list via `systeminformation` + secure IPC |
| **Android** | Capacitor (`android/`) | Device info, RAM in use, storage, and live network status via official Capacitor plugins |
| Browser (dev/preview) | any | Simulated demo data |

> Note: Electron itself does not run on Android, so the Android build uses Capacitor — the standard way to ship a web codebase as a native Android app. Both targets render the exact same UI in `app/`.

## Project layout

```
servicepulse/
├── app/                  # Shared web UI (index.html, styles.css, app.js) — platform-adaptive
├── electron/             # Windows desktop app (Electron main + preload, contextIsolation on)
│   └── app/              # synced copy of ../app (build artifact)
├── android/              # Android app (Capacitor config + generated native project)
│   ├── www/              # synced copy of ../app (build artifact)
│   └── android/          # native Android Studio project (generated by `cap add android`)
└── scripts/sync-web.js   # copies app/ into both build targets
```

## Features

- Live CPU load with a scrolling history chart (fast initial sampling burst, then 3s cadence)
- Memory usage meters with GB totals
- Running services table (Windows/Electron): sortable by name/PID/CPU/memory, live filter search, health status pills (healthy / elevated / critical)
- Android: device details panel (model, Android version, storage, network type), memory history chart, live network change listener
- Pause/resume live refresh
- Dark terminal-inspired theme, responsive down to phone widths, works fully offline

## Windows (Electron)

Requirements: Node.js 18+.

```bash
cd electron
npm install
npm start          # runs the app (auto-syncs the shared UI first)
```

### Build a Windows installer (.exe NSIS installer)

```bash
cd electron
npm run dist       # produces electron/dist/ServicePulse-Setup-1.0.0.exe
```

Requires Windows (or Wine) for signing/packaging; `npm start` works for development on any OS.

## Android (Capacitor)

Requirements: Android Studio (with SDK 34+) and JDK 17.

```bash
cd android
npm install                 # already done if you ran sync
npm run build               # syncs web assets + plugins, builds debug APK
```

The debug APK lands in `android/android/app/build/outputs/apk/debug/`.

Or open the project in Android Studio:

```bash
cd android
npx cap open android       # then press Run
```

### Making changes to the UI

Edit only `app/`. Then refresh both targets:

```bash
node scripts/sync-web.js               # copies app/ -> electron/app and android/www
cd android && npx cap sync android     # push web assets + plugins into the native project
```

## Security notes (Electron)

- `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`
- Renderer talks to the main process only through a minimal read-only bridge (`preload.js` → `ipcMain.handle`)
- Strict CSP in `index.html`; no remote code

## Test harness

The Electron main process supports a screenshot mode for CI/QA:

```bash
SP_SHOT=/tmp/shot.png SP_SHOT_DELAY=8000 npx electron .
```
